# 小黑的宝藏 — 博客使用指南

## 一、项目原理（这个网站是怎么工作的）

### 核心概念：静态博客

你的博客是一个 **静态网站**，和 WordPress、微信公众号那种"动态网站"有本质区别：

| | 静态博客（你的网站） | 动态博客（WordPress等） |
|---|---|---|
| 内容存储 | 纯文本文件（Markdown） | 数据库 |
| 生成方式 | 本地电脑编译 → 生成 HTML 文件 | 服务器实时从数据库读取 |
| 访问速度 | 极快（纯 HTML，无数据库查询） | 较慢（每次访问都要查数据库） |
| 费用 | 几乎免费（只是文件托管） | 需要服务器 + 数据库，有月费 |
| 安全性 | 极高（没有后台可被攻击） | 需要维护安全更新 |
| 缺点 | 每次改内容需要重新"编译部署" | 随时在线编辑 |

### 工作流程

```
你写 Markdown 文章
       ↓
运行 pnpm build（编译命令）
       ↓
生成 dist/ 文件夹（纯 HTML + CSS + JS）
       ↓
把 dist/ 上传到服务器
       ↓
别人通过域名访问 → 看到你的博客
```

### 技术栈说明

- **Astro** — 博客框架（负责把 Markdown 编译成网页）
- **Svelte** — 交互组件（搜索框、设置面板等需要"动"的部分）
- **Tailwind CSS** — 样式系统（控制颜色、间距、字体等外观）
- **Markdown** — 你写文章用的格式（类似简化的 Word，用纯文本排版）
- **pnpm** — 包管理器（管理项目用到的各种代码库）

### 项目目录结构


## 二、部署（已完成配置）

### 当前部署架构

```
你写 Markdown 文章
       ↓
git push → GitHub 接收代码
       ↓
Vercel 自动运行 pnpm build 编译
       ↓
编译产物部署到全球 CDN
       ↓
别人访问 www.blackboytreasure.cn → 看到你的博客
```

- **平台**：Vercel（免费，自动 HTTPS，全球 CDN）
- **域名**：`www.blackboytreasure.cn`（腾讯云域名，已绑定 Vercel）
- **触发方式**：每次 `git push` 自动触发，无需手动操作
- **部署耗时**：约 2-3 分钟

### 发布一篇新文章的完整流程

```bash
# 1. 本地预览确认没问题
pnpm dev          # 打开 http://localhost:4321 查看

# 2. 验证生产构建不会报错（重要！）
pnpm build

# 3. 推送到线上
git add -A
git commit -m "feat: 发布文章《标题》"
git push
```

### 如果部署失败

Vercel 构建失败时线上保持旧版本不中断，不用担心网站挂掉：
1. 本地运行 `pnpm build`，查看报错信息
2. 修复错误后重新 commit + push
3. 到 [Vercel Dashboard](https://vercel.com) 确认最新部署状态为 Ready

## 三、内容管理：怎么编辑网站

### 当前方式：编辑 Markdown 文件

这是静态博客最核心的工作方式——**用文本文件写文章**。

#### 新建一篇博客文章

1. 在 `src/content/posts/` 下创建一个 `.md` 文件，例如 `my-first-post.md`
2. 文件开头写"元信息"（frontmatter），然后空一行，写正文：

```markdown
---
title: 我的第一篇博客
published: 2026-08-12
description: 这是我博客的开篇文章
tags: [生活, 日记]
category: 日常
---

## 你好世界

这是我写的第一篇博客文章。

Markdown 很简单：
- **加粗** 用两个星号
- *斜体* 用一个星号
- [链接](https://example.com) 用方括号
- 图片用 ![描述](图片路径)
```

3. 保存后，开发服务器会自动刷新（热更新），你在浏览器就能看到
4. 发布时运行 `pnpm build`，新文章就会包含在编译产物中

#### 常用 Markdown 语法速查

```
# 一级标题     ## 二级标题     ### 三级标题
**加粗文字**   *斜体文字*     ~~删除线~~
- 无序列表     1. 有序列表
> 引用文字
`代码`        ```代码块```
![图片名](图片路径)
[链接文字](网址)
```

#### 编辑现有文章

直接修改 `src/content/posts/` 下对应的 `.md` 文件即可。

#### 删除文章

删除对应的 `.md` 文件，重新编译即可。

### 关于"Notion 联动"

**直接联动 Notion 做为后台编辑器：目前不支持**，但有两种替代方案：

#### 方案 1：Notion 导出 Markdown（手动）

1. 在 Notion 里写好文章
2. 选择"导出 → Markdown"
3. 把导出的 `.md` 文件放到 `src/content/posts/` 目录
4. 添加 frontmatter（标题、日期等元信息）
5. 编译部署

**优点**：可以继续用 Notion 的舒适编辑体验
**缺点**：需要手动操作，图片需要单独处理

#### 方案 2：Git-based CMS（推荐，半自动）

使用类似 **TinaCMS** 或 **Decap CMS** 的工具：
- 提供一个网页版编辑器（类似简化版 Notion）
- 编辑后自动保存到代码仓库
- 触发自动编译部署

这需要一些额外配置，等你熟悉基本流程后可以帮你加。

#### 方案 3：Notion API 自动同步（高级）

写一个脚本：
1. 定期从 Notion 拉取指定数据库里的文章
2. 自动转换为 Markdown 格式
3. 自动提交到项目仓库
4. 触发自动编译部署

这个最方便但配置最复杂，可以后续帮你实现。

## 四、日常操作速查

| 想做什么 | 怎么做 |
|---|---|
| 本地预览博客 | 终端运行 `pnpm dev`，打开 http://localhost:4321 |
| 写新文章 | 在 `src/content/posts/` 新建 `.md` 文件 |
| 改网站名称/头像等 | 修改 `src/config/` 下的配置文件 |
| 改导航栏菜单 | 修改 `src/config/navBarConfig.ts` |
| 改壁纸/横幅文字 | 修改 `src/config/backgroundWallpaper.ts` |
| 发布到线上 | `pnpm build`（验证）→ `git add -A && git commit -m "描述" && git push` |
| 新建微动态 | 运行 `pnpm new-d` 或在 `src/content/dynamic/` 新建 `.md` |
