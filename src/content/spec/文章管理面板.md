## 已发布的文章

```dataview
TABLE published AS 发布日期, category AS 分类, join(tags, ", ") AS 标签
FROM "src/content/posts"
WHERE draft != true
SORT published DESC
```

## 草稿箱

```dataview
TABLE published AS 创建日期, category AS 分类
FROM "src/content/posts"
WHERE draft = true
SORT published DESC
```

## 最近修改

```dataview
TABLE published AS 发布日期, file.mtime AS 最后修改
FROM "src/content/posts"
WHERE draft != true
SORT file.mtime DESC
LIMIT 10
```

## 按分类统计

```dataview
TABLE length(rows) AS 文章数
FROM "src/content/posts"
WHERE draft != true AND category
GROUP BY category
SORT length(rows) DESC
```
