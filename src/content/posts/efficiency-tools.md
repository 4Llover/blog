工欲善其事，必先利其器。分享一下我在学习和开发中用到的效率工具。

## 笔记与知识管理

### Obsidian

基于 Markdown 的本地笔记软件，双向链接和图谱视图是杀手级功能。配合丰富的插件生态，可以搭建出强大的个人知识管理系统。

- 官网：https://obsidian.md/
- 插件社区：https://pkmer.cn/

### PKMer

Obsidian 的中文插件社区，有很多优质插件和使用教程，比去 GitHub 找插件方便很多。

- 网址：https://pkmer.cn/

## 文献管理

### Zotero

开源的文献管理工具，浏览器插件一键抓取，支持 PDF 标注和笔记。搭配 Zotero Connector 使用体验极佳。

- 官网：https://www.zotero.org/
- 中文插件商店：https://zotero-chinese.com/plugins/

## 开发工具

### Apifox

API 文档、调试、Mock、测试一体化平台。比 Postman 更适合国内开发者的使用习惯，界面也更清爽。

- 官网：https://apifox.com/

### GitHub

全球最大代码托管平台，不多介绍了。

- 网址：https://github.com/

### Vercel

前端部署平台，push 代码自动部署，免费额度对个人项目完全够用。本站就部署在 Vercel 上。

- 官网：https://vercel.com/

## 实用网站

### 吾爱破解

技术交流论坛，软件逆向、系统优化、实用工具分享，宝藏社区。

- 网址：https://www.52pojie.cn/

### 黑域基地

良心软件收集站，推荐的软件都很实用。

- 网址：https://www.hybase.com/

### PanHunt

网盘搜索导航，收录了多个网盘搜索引擎，找资源很方便。

- 网址：https://panhunt.com/

### Z-Library

全球最大的电子书库，学术书籍和教材基本都能找到。

- 网址：https://z-lib.io/

工具不在多，适合自己最重要。以上都是我实际在用的，推荐给大家。
